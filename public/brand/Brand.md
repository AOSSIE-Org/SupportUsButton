## ✍️ Typography

- **Default Font Family:** **Inherited (`font-inherit`)** (Automatically adapts to host application typography)
- **Fallback Stack:** `ui-sans-serif, system-ui, -apple-system, sans-serif`
- **Configuration:** Set dynamically via parent DOM computed style traversal (`useParentStyles` hook) and native CSS transparency (`font-inherit`).
